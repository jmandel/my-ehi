Published data files

Shared browser data lives under data/ in the published site.

  • data/ehi.sqlite — browser SQLite database built from the redacted EHI table export during publish.
  • data/fs.zip — normal zip archive of git-tracked reading skill files plus redacted rich-text note files used by the agent harness filesystem.
  • data/core-prompt.txt — the top-level Epic EHI reading skill text loaded into the harness system prompt.
  • data/sql-wasm.wasm — sql.js WebAssembly runtime loaded by the browser harness.
