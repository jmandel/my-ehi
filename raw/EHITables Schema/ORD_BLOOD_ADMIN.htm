ORD_BLOOD_ADMIN
Description:
Administrable Procedure Items in Orders (ORD).

Primary Key
Column NameOrdinal Position
ORDER_ID1

Column Information
NameTypeDiscontinued?
1ORDER_IDNUMERICNo
The unique ID of the child/instance order that is associated with transfusion documentation for a unit of blood.
2ADMIN_PX_TYPE_C_NAMEVARCHARNo
Type for procedure that can be administered.
3BLOOD_UNIT_NUMVARCHARNo
The primary identifier for the blood product. This is not necessarily unique. Populated via interface, or administration form for procedures.
4BLOOD_CODING_SYS_C_NAMEVARCHARNo
Specifies the coding system used for the Unit Number. Some examples are ISBT 128 and Codabar.
5BLOOD_UNIT_NM_SRC_C_NAMEVARCHARNo
Indicates if populated through interface or by user.
6BLOOD_PRODUCT_CODEVARCHARNo
Secondary identifier to be paired with unit number (when dealing with divisions of a unit of blood).
7BLOOD_EXPIRATN_INSTDATETIME (Local) No
The expiration instant as specified on the unit of blood. This may be populated by the interface.
8BLOOD_START_INSTANTDATETIME (Local) No
Based on administration actions, the start of the transfusion.
9BLOOD_END_INSTANTDATETIME (Local) No
Based on administration actions, the end of the transfusion.
10BLOOD_UNIT_RES_IDNUMERICNo
Corresponds to the Interfaced information about the scanned unit.
11BLOOD_CODABAR_REGVARCHARNo
The CODABAR registration number from the bag of blood associated with this order.
12IS_BLOOD_YNVARCHARNo
This column will be Yes if this procedure is a prepare or transfuse blood order that uses the transfuse or prepare amount display items.
13TRANSFUSE_AMOUNTINTEGERNo
If this is a blood transfusion order, this column is the amount of blood that was ordered.
14TRANSFUSE_AMOUNT_UNIT_C_NAMEVARCHARNo
If this is a blood transfusion order, this is the unit in which it was ordered.
15PREPARE_AMOUNTINTEGERNo
If this is a blood prepare order, this column is the amount of blood that was ordered.
16PREPARE_AMOUNT_UNIT_C_NAMEVARCHARNo
If this is a blood prepare order, this is the unit in which it was ordered.
17WEIGHT_BLD_AMOUNTNUMERICNo
The weight-based amount this blood prepare or transfuse order was placed in.
18WEIGHT_BLD_UNIT_C_NAMEVARCHARNo
The weight-based unit this blood prepare or transfuse order was placed in.
19BLOOD_MAIN_ADMININTEGERNo
The administration line in ORD 11000 holding the main blood details.
20BLOOD_PRODUCT_TYP_C_NAMEVARCHARNo
Identify the blood product type when using universal blood procedures.
