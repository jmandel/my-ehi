DENTAL_FINDING_NOADD
Description:
This table contains the items for dental finding records.

Primary Key
Column NameOrdinal Position
FINDING_ID1

Column Information
NameTypeDiscontinued?
1FINDING_IDNUMERICNo
The unique identifier for the finding record
2DEN_TOO_FIND_TYPE_C_NAMEVARCHARNo
Indicates the type of finding, such as caries, fracture, etc.
3FINDING_STAT_NOAD_C_NAMEVARCHARNo
The current status the finding's status (unaddressed, resolved, removed, etc.) of the dental finding
4DENTAL_CARIES_CLS_C_NAMEVARCHARNo
Stores the caries classification of a caries finding
5DENTAL_CARIES_DEPTHNUMERICNo
Stores the caries depth of a caries finding
6DENTAL_MOBI_CLASS_C_NAMEVARCHARNo
Stores information about the severity of mobility documented on a tooth.
7DENTAL_FURC_CLASS_C_NAMEVARCHARNo
Stores information about the severity of furcation documented on a tooth.
8DENT_CARIES_INCIP_C_NAMEVARCHARNo
This columns specifies the incipiency of a caries finding.
9DENT_FND_OVR_NAMEVARCHARNo
This item specifies the display name that will be used when users document a finding. If populated, this will be used in place of the finding type (I RES 17407) to describe the finding.
