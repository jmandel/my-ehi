MED_CVG_USERACTION
Description:
This table holds information about user actions taken on Patient Estimates.

Primary Key
Column NameOrdinal Position
MED_ESTIMATE_ID1
CONTACT_DATE_REAL2
LINE3

Column Information
NameTypeDiscontinued?
1MED_ESTIMATE_IDNUMERICNo
The unique identifier (.1 item) for the medication estimate record.
2CONTACT_DATE_REALFLOATNo
A unique contact date in decimal format. The integer portion of the number indicates the date of contact. The digits after the decimal distinguish different contacts on the same date and are unique for each contact on that date. For example, .00 is the first/only contact, .01 is the second contact, etc.
3LINEINTEGERNo
The line number for the information associated with this contact. Multiple pieces of information can be associated with this contact.
4CONTACT_DATEDATETIMENo
The date of this contact in calendar format.
5UAC_EMP_IDVARCHARNo
This item stores the user (EMP) record ID of the user who either selects a medication alternative or keeps the original one in Patient Estimates.
6UAC_EMP_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
7UAC_SEL_ALT_YNVARCHARNo
Store whether user selects alternative medication from this LME.
8UAC_INS_UTC_DTTMDATETIME (UTC) No
Stores the instant (date and time in UTC) a user selected an alternative medication from this LME.
9UAC_LME_IDNUMERICNo
Stores the LME .1 (record ID) of the LME record containing the selected alternative.
10UAC_LME_CSNNUMERICNo
Stores the contact serial number (CSN) of the LME record containing the selected alternative.
11UAC_LME_LN_NUMINTEGERNo
Stores the line number containing the selected alternative in superitem LME 300 of the alternative LME record.
