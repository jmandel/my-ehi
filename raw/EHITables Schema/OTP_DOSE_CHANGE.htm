OTP_DOSE_CHANGE
Description:
The dose change history for an order template.

Primary Key
Column NameOrdinal Position
OTP_ID1
LINE2

Column Information
NameTypeDiscontinued?
1OTP_IDNUMERICNo
The order template ID.
2LINEINTEGERNo
The line number that corresponds to a dose change of the order template in this record.
3DOSE_CHANGE_TYP_C_NAMEVARCHARNo
The type of dose change made to the order template in this record, such as Initial Dose, Order Composer, Dose Modification, or Change Propagation.
4DOSE_CHANGE_INSTDATETIME (Local) No
The date/time in external format when a dose of the order template in this record was changed.
5DOSE_CHANGE_USER_IDVARCHARNo
The user ID of the person who made the dose change to the order template in this row.
6DOSE_CHANGE_USER_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
7DOSE_CHANGE_AMTVARCHARNo
The new dose of the order template in this row.
8DOSE_CHANGE_UNIT_C_NAMEVARCHARNo
The dose unit for the new dose of the order template in this row.
9DOSE_CHANGE_RSN_C_NAMEVARCHARNo
The reason for the dose change to the order template in this row.
10DOSE_CHANGE_COMMENTVARCHARNo
User free text comment on the reason for the dose change to the order template in this row.
11DOSE_CHANGE_PCTNUMERICNo
The percentage change (positive or negative) made to the dose of the order template in this row.
