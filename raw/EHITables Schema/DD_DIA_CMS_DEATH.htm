DD_DIA_CMS_DEATH
Description:
This table contains data elements submitted for CMS ESRD death forms (CMS-2746).

Primary Key
Column NameOrdinal Position
REGISTRY_DATA_ID1

29GRAFT_FUNC_DEATH_DIA_CMS_YNU_C_NAMEVARCHARNo

31RECV_HOSPIC_CARE_DIA_CMS_YNU_C_NAMEVARCHARNo

32TREATMENT_PROV_ID_PROV_NAMEVARCHARNo
