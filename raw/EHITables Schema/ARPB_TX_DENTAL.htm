ARPB_TX_DENTAL
Description:
This table is used for dental related transaction information.

Primary Key
Column NameOrdinal Position
TX_ID1

Column Information
NameTypeDiscontinued?
1TX_IDNUMERICNo
The unique identifier for the transaction record.
2TOOTH_NUM_C_NAMEVARCHARNo
The tooth number category ID for the charge.
3ARCH_C_NAMEVARCHARNo
Displays the dental arch used for the procedure. The value displayed will be either Upper or Lower.
4QUADRANT_C_NAMEVARCHARNo
Displays the dental quadrant used for the procedure. The value displayed could be one of several options, such as Lower Left or Maxillary Area.
5AREAVARCHARNo
Displays the dental area used for the procedure. The displayed value will be a range of teeth. For example 1-2,10-B, or A-B.
6SUPERNUMERARY_YNVARCHARNo
Indicates whether multiple teeth are present in the socket.
7FOLLOW_UP_MONTHSINTEGERNo
The number of months after which this procedure requires follow-up.
8HYGIENIST_PROV_ID_PROV_NAMEVARCHARNo
The name of the service provider. This item may be hidden in a public view of the CLARITY_SER table.
9TREATMENT_PLAN_IDVARCHARNo
The unique ID of the treatment plan used in this procedure.
10FOLLOW_UP_DATEDATETIMENo
Displays the date the recall must be made by.
11DENTAL_CHG_TYPE_C_NAMEVARCHARNo
Indicates what type of orthodontic or predetermination charge it is.
12DENTAL_PREAUTH_AMTNUMERICNo
The amount that gets set on predetermination claims for the predetermination dental charge.
13DENTAL_PREAUTH_QTYINTEGERNo
The quantity that gets set on predetermination claims for the predetermination dental charge.
14CHARGING_PLAN_LINEINTEGERNo
The line of the dental charging plan that led to the charge being dropped.
