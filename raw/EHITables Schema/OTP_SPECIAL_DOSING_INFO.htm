OTP_SPECIAL_DOSING_INFO
Description:
This table contains special dosing information that is stored in the patient order template.

Primary Key
Column NameOrdinal Position
OTP_ID1
LINE2

Column Information
NameTypeDiscontinued?
1OTP_IDNUMERICNo
The unique identifier for the patient order template record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3SPEC_DOSING_PARAM_C_NAMEVARCHARNo
The category number for the dosing parameter type. This is usually the same as the internal ID. If you use IntraConnect, this is the Community ID (CID).
4SPEC_AMOUNTVARCHARNo
The dosing parameter amount. This is shared between all dosing parameters and may represent a dose or time.
5SPEC_DOSE_UNIT_C_NAMEVARCHARNo
The dose unit category value. This will only populate for rows with an appropriate dosing parameter (Time-based units are stored in a different item).
6SPEC_TIME_UNIT_C_NAMEVARCHARNo
The time unit for dosing parameters such as lockout interval that are in time rather than a dose unit.
7PARAM_CALC_AMTVARCHARNo
The calculated version of the dosing parameter amount.
8PARAM_CALC_UNIT_C_NAMEVARCHARNo
The unit of the calculated amount.
9PARAM_CALC_CALCVARCHARNo
The details on how the calculated dosing information was obtained.
