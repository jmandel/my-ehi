AUTH_REQUEST_HX
Description:
This table contains a snapshot of information about an individual authorization request as of a point in time.

Primary Key
Column NameOrdinal Position
AUTH_REQUEST_ID1
CONTACT_DATE_REAL2

Column Information
NameTypeDiscontinued?
1AUTH_REQUEST_IDNUMERICNo
The unique identifier for the authorization request.
2CONTACT_DATE_REALFLOATNo
A unique contact date in decimal format. The integer portion of the number indicates the date of contact. The digits after the decimal distinguish different contacts on the same date and are unique for each contact on that date. For example, .00 is the first/only contact, .01 is the second contact, etc.
3AUTH_REQUEST_CNCT_TYPE_C_NAMEVARCHARNo
The contact type category ID for the authorization request.
4UM_STATUS_C_NAMEVARCHARNo
The status category ID for the authorization request.
5CONTACT_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) of the authorization request contact. If this contact is a draft, this column holds the date and time that this draft contact was created. If this contact is published, this column holds the date and time that it was published.
6HISTORY_USER_IDVARCHARNo
The unique ID of the user record of the user who created this contact. This column is frequently used to link to the CLARITY_EMP table.
7HISTORY_USER_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
8AUTH_REQUEST_TYPE_C_NAMEVARCHARNo
The request type category ID for the authorization request.
9INSTANT_OF_ENTRY_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) of when the authorization request contact was edited.
10FINALIZED_STATUS_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) the finalized status was made on the authorizations in this request.
11SUBMISSION_OVRIDE_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) of the user-override value for the authorization request submission.
12SUBMISSION_RPT_UTC_DTTMDATETIME (UTC) No
The reported submission date and time (UTC) of the authorization request. If an override value is set, the override value is shown. Otherwise, this is the system-calculated value.

The date and time (UTC) of the user-override value for the authorization request decision.
14DECISION_RPT_UTC_DTTMDATETIME (UTC) No

16ADDL_INFO_REQ_OVRIDE_UTC_DTTMDATETIME (UTC) No

17ADDL_INFO_RCPT_SYS_UTC_DTTMDATETIME (UTC) No
The system-calculated date and time (UTC) of the additional information receipt.
18ADDL_INFO_RCPT_OVRIDE_UTC_DTTMDATETIME (UTC) No
The user-override date and time (UTC) of the additional information receipt instant.
19PEER_TO_PEER_OFFER_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) that the peer-to-peer review was offered.
20PEER_TO_PEER_COMPLETE_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) that the peer-to-peer review was completed.
21PRIORITY_C_NAMEVARCHARNo
The unique ID of the priority of the authorization request.
22RFL_TYPE_C_NAMEVARCHARNo
The service type of the authorization request. This is used for authorization requests opened in Authorization Review.
23SERVICE_REQUESTER_C_NAMEVARCHARNo
The unique ID of the requester of the authorization request.
24MEM_RESP_GUIDVARCHARNo
A unique key representing the authorized representative associated with the authorization request. This can be used to join to table MEMBER_RESP_PERSON on MEM_RESP_GUID to report on demographic information associated with the authorized representative.
25REF_BY_IS_CONTRACTED_SYS_YNVARCHARNo
The system-calculated value of whether the referred by entity is contracted or not.
26REF_BY_IS_CONTRACTED_OVRIDE_YNVARCHARNo
The user-override value of whether the referred by entity is contracted or not.
27REF_TO_IS_CONTRACTED_SYS_YNVARCHARNo
The system-calculated value of whether the referred to entity is contracted or not.
28REF_TO_IS_CONTRACTED_OVRIDE_YNVARCHARNo
The user-override value of whether the referred to entity is contracted or not.
29MED_DIRECTOR_REVIEW_YNVARCHARNo
Indicates whether medical director review was performed on this authorization request.
30MED_DIRECTOR_REVIEW_USER_IDVARCHARNo
The unique ID of the user who performed medical director review.
31MED_DIRECTOR_REVIEW_USER_ID_NAMEVARCHARNo

33PEER_TO_PEER_STATUS_C_NAMEVARCHARNo
The unique ID of the status of the peer-to-peer review offer.
34ADDL_INFO_EXTENSION_TAKEN_YNVARCHARNo
Whether an additional information request extension was taken for the authorization request.
35MANUAL_EXTENSION_DAYSINTEGERNo
The number of manual extension days taken for the authorization request.
36SUBMISSION_SYS_UTC_DTTMDATETIME (UTC) No
The date and time (UTC) of the system-calculated value for the authorization request submission instant, based on associated communications with a purpose of Request for Authorization.
37DECISN_UM_STATUS_CHANGE_SRC_C_NAMEVARCHARNo
The change source category ID that resulted in the decision status being set for the authorization request.
38HISTORY_EDIT_SOURCE_C_NAMEVARCHARNo

The unique ID of the user who has taken the manual extension days.
46MAN_EXT_DAYS_USER_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.

The instant of the request to expedite communication in UTC time zone.
50RQST_TO_EXPEDITE_COMM_IDVARCHARNo
