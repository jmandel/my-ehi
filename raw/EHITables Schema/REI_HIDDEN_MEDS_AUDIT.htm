REI_HIDDEN_MEDS_AUDIT
Description:
This table lists changes to the medications that have been hidden or unhidden in the Stimulation Summary activity. When users hide or unhide medications, a line is added along with who made the change and the exact instant.

Primary Key
Column NameOrdinal Position
CYCLE_ID1
LINE2

Column Information
NameTypeDiscontinued?
1CYCLE_IDNUMERICNo
The unique identifier (.1 item) for the cycle record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3HIDDEN_AUDIT_PAT_IDVARCHARNo
Stores the patient record ID for the patient that has a medication hidden/unhidden (Multiple patients can be linked to a single cycle record).
4HIDDEN_AUDIT_MED_PRBLM_LIST_IDNUMERICNo
Stores the ID for the simple generic form of the hidden/unhidden medication.
5HIDDEN_AUDIT_DISP_QTYUNIT_C_NAMEVARCHARNo
Stores the units of the hidden/unhidden medication.
6HIDDEN_AUDIT_FREQ_IDVARCHARNo
Stores the frequency ID of the hidden/unhidden medication.
7HIDDEN_AUDIT_FREQ_ID_FREQ_NAMEVARCHARNo
The name of the frequency record.
8HIDDEN_AUDIT_MED_ROUTE_C_NAMEVARCHARNo
Stores the route of the hidden/unhidden medication.
9HIDDEN_AUDIT_MEDICATION_ID_MEDICATION_NAMEVARCHARNo
The name of this medication record.
10HIDDEN_AUDIT_USER_IDVARCHARNo
Stores the user ID that hid/unhid the medication.
11HIDDEN_AUDIT_USER_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
12HIDDEN_AUDIT_INST_UTC_DTTMDATETIME (UTC) No
The instant in which the medication was hidden/unhidden.
13HIDDEN_AUDIT_STATUS_YNVARCHARNo
Status of whether or not the medication is hidden.
