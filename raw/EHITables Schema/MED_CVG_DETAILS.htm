MED_CVG_DETAILS
Description:
This table holds details about medication coverages.

Primary Key
Column NameOrdinal Position
MED_ESTIMATE_ID1
CONTACT_DATE_REAL2
LINE3

Column Information
NameTypeDiscontinued?
1MED_ESTIMATE_IDNUMERICNo
The unique identifier (.1 item) for the medication estimate record.
2CONTACT_DATE_REALFLOATNo
A unique contact date in decimal format. The integer portion of the number indicates the date of contact. The digits after the decimal distinguish different contacts on the same date and are unique for each contact on that date. For example, .00 is the first/only contact, .01 is the second contact, etc.
3LINEINTEGERNo
The line number for the information associated with this contact. Multiple pieces of information can be associated with this contact.
4CONTACT_DATEDATETIMENo
The date of this contact in calendar format.
5PHR_TYPE_C_NAMEVARCHARNo
Holds the category value indicating the pharmacy type that is covered.
6DRUG_STATUS_C_NAMEVARCHARNo
Holds the category value of the drug coverage status.
7QTY_PRICEDINTEGERNo
Holds the quantity priced.
8QTY_PRICED_UNIT_C_NAMEVARCHARNo
Holds the category value indicating the unit for the quantity priced.
9DAYS_SUPPLYINTEGERNo
Holds the days supply priced.
10PLAN_PAY_AMTNUMERICNo
Holds the plan pay amount.
11PAT_PAY_AMTNUMERICNo
Holds the estimated patient pay amount.
12OOP_APPLIED_AMTNUMERICNo
Holds the out of pocket applied amount.
13OOP_REMAIN_AMTNUMERICNo
Holds the out of pocket remaining amount.
14DEDUCT_APPLY_AMTNUMERICNo
Holds the deductible applied amount.
15DEDUCT_REMAIN_AMTNUMERICNo
Holds the deductible remaining amount.
16FORM_STATUSVARCHARNo
Holds the formulary status.
17PA_REQ_C_NAMEVARCHARNo
Holds whether prior authorization is required for this medication. This is the effective prior authorization flag after considering system overrides. The actual value returned in the RTPB response is in item LME 322.
18PHARMACY_IDNUMERICNo
This item holds a pointer to the pharmacy (PHR) that was used for generating this estimate.
19PHARMACY_ID_PHARMACY_NAMEVARCHARNo
The name of the pharmacy.
20PRIMARY_CVG_YNVARCHARNo
This item indicates if this line holds the coverage information that matches what was originally requested.
21DISPLAYED_BEFORE_SIGN_YNVARCHARNo
This item indicates if this line of coverage data was displayed to an end-user before the order was signed.
