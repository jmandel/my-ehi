AP_CLAIM_EXPORT_HISTORY
Description:
This table contains the history of a claim's outgoing 837 exports and encounter reporting data.

Primary Key
Column NameOrdinal Position
CLAIM_ID1
LINE2

Column Information
NameTypeDiscontinued?
1CLAIM_IDNUMERICNo
The unique identifier for the claim record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3EXPORT_TYPE_C_NAMEVARCHARNo
The export type for this row of export history.
4EXPORT_SUBTYPE_C_NAMEVARCHARNo
The export subtype for this row of export history, if there is a subtype for the export.
5EXPORT_BATCH_PAYER_ID_PAYOR_NAMEVARCHARNo
The name of the payor.
6CLAIM_RUN_IDENTINTEGERNo
The export batching claim run ID that processed and includes this claim. If a claim errored during processing due to edit checks, no claim run identifier is set in this column.
7CLAIM_RECON_IDVARCHARNo
The unique ID of the Claim Reconciliation record that tracks the encounter and reconciliation data for this row.
8EXPORT_DEST_PAYER_ID_PAYOR_NAMEVARCHARNo
The name of the payor.
9EXPORT_CEV_RECORD_IDNUMERICNo
The unique ID of the most recent claim values record created for this row's outgoing claim export data.
