CYCLE_EMBRYO_TRANSFER
Description:
This table holds data for the specific embryos transferred during a cycle.

Primary Key
Column NameOrdinal Position
RECORD_ID1
LINE2

Column Information
NameTypeDiscontinued?
1RECORD_IDNUMERICNo
The unique identifier for the cycle record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3EMBRYO_STAGE_C_NAMEVARCHARNo
Stores stage at transfer for a specific embryo.
4EMBRYO_GRADE_C_NAMEVARCHARNo
Stores grade at transfer for a specific embryo.
5EMBRYO_FERT_METHOD_C_NAMEVARCHARNo
Stores the embryo's fertilization type at a given transfer.
6EMBRYO_ASSISTED_HATCHING_YNVARCHARNo
Stores whether this specific embryo had any hatching assistance.
7EGG_EMBRYO_GAMETE_SOURCE_C_NAMEVARCHARNo
Stores the source of the egg for a specific embryo. The source being the participant that the gamete came from (donor, partner, self, etc).
8SPERM_EMBRYO_GAMETE_SOURCE_C_NAMEVARCHARNo
Stores the sperm source for a specific embryo. The source being the participant that the gamete came from (donor, partner, etc).
9EGG_EMBRYO_GAMETE_STATE_C_NAMEVARCHARNo
Stores the state of the egg at the beginning of the cycle.
10SPERM_EMBRYO_GAMETE_STATE_C_NAMEVARCHARNo
Stores the state of the sperm at the beginning of the cycle.
11EMBRYO_COMMENTSVARCHARNo
Stores the comments for a specific embryo at transfer.
12EMBRYO_TRANSFER_DAYINTEGERNo
Stores the transfer day of a specific embryo.
13EMBRYO_OVERRIDEVARCHARNo
Stores an embryo ID that a user specified. If not set, an embryo ID based on the line number (such as "Embryo 1") is shown to the end user.
14EMBRYO_PGT_A_C_NAMEVARCHARNo
Stores the documentation for a specific embryo's PGT-A testing during an embryo transfer.
15EMBRYO_PGT_M_C_NAMEVARCHARNo
Stores the documentation for a specific embryo's PGT-M testing during an embryo transfer.
16EMBRYO_PGT_SR_C_NAMEVARCHARNo
Stores the documentation for a specific embryo's PGT-SR testing during an embryo transfer.
17SPECIFIC_EMBRYO_GAMETE_STATE_C_NAMEVARCHARNo
Stores the state of the embryo (thawed or fresh) at the beginning of the cycle. Thawed means the embryo was thawed as an embryo. Fresh means that either the egg and sperm are fresh, or they were thawed as gametes and then fertilized.
18EMBRYO_DONATED_YNVARCHARNo
Stores whether the embryo was donated for an embryo transfer cycle.
