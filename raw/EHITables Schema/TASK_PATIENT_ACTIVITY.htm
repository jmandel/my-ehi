TASK_PATIENT_ACTIVITY
Description:
This table contains data about patient tasks assigned by MyChart Care Companion.

Primary Key
Column NameOrdinal Position
ACTIVITY_ID1

Column Information
NameTypeDiscontinued?

42COMPLETED_INST_CNTINTEGERNo
