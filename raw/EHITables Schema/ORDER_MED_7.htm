Description:
This table enables you to report on medications ordered. This table should be used with ORDER_MED.

Response to a question that a user is shown when reordering or modifying an outpatient order while the patient is admitted to a residential care facility.
20MED_ORIG_DOSAGE_END_DATEDATETIMENo
Stores the original dosage end date for a medication order when using the wide end date feature if it was changed after the order was signed
21SCHED_FIRST_DOSE_DTTMDATETIME (Local) No

This number is unique across all patient encounters in your system. If you use IntraConnect, this is the Unique Contact Identifier (UCI).
25SCHEDULE_USING_METHOD_C_NAMEVARCHARNo

27REMAINING_DOSES_BEFORE_INTAKEINTEGERNo

28MED_CHG_REPLACE_YNVARCHARNo
