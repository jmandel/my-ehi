RES_COMPONENTS
Description:
Primary table for result component information.

Primary Key
Column NameOrdinal Position
RESULT_ID1
LINE2

Column Information
NameTypeDiscontinued?
1RESULT_IDVARCHARNo
The unique identifier of the result record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3COMPONENT_IDNUMERICNo
Internal component ID
4COMPONENT_ID_NAMEVARCHARNo
The name of the component.
5COMPONENT_RESULTVARCHARNo
Component result interpreted value
6COMPONENT_VALUEVARCHARNo
Component result value
7COMPONENT_UNITSVARCHARNo
Component result units
8COMPONENT_ABN_C_NAMEVARCHARNo
Component abnormal category value
9COMPONENT_DELTA_YN_NAMEVARCHARNo
If this value is 1 (true), it indicates that a delta has occurred for this component.
10COMPONENT_NRML_LOVARCHARNo
This item specifies the lowest "normal" value for this component if applicable.
11COMPONENT_NRML_HIVARCHARNo
This item specifies the highest "normal" value for this component, if applicable.
12COMPONENT_CMTVARCHARNo
This item allows entry of a free-text comment related specifically to this component.
13COMPONENT_MTHD_IDVARCHARNo
The testing method for this component.
14COMPONENT_MTHD_ID_METHOD_NAMEVARCHARNo
The name of the instrument interface, method, method grouper, or middle tier interface record.
15COMPONENT_RANGEVARCHARNo
The normal range for the component or a list of values that are considered normal.
16COMPONENT_INSTDATETIME (Local) No
The instant the component was resulted.
17COMPONENT_LAB_ID_LAB_NAMEVARCHARNo
The name of the lab record.
18COMPONENT_REPORT_YN_NAMEVARCHARNo
This item indicates whether or not a component should be reported.
19COMPON_DILUTIONVARCHARNo
The factor by which the value is diluted
20COMPON_LINEAR_YNVARCHARNo
The linearity flag for this component
21COMPON_RPT_SET_BY_C_NAMEVARCHARNo
Indicates how the report flag for this component was determined
22COMPON_REPORTABLE_C_NAMEVARCHARNo
The reportable (notifiable) flag for this component
23COMP_VAL_STAT_C_NAMEVARCHARNo
The validation status category number for this component.
24COMP_VERIF_STATUS_C_NAMEVARCHARNo
The verification status category number for this component.
25COMP_VERIF_LAB_ID_LAB_NAMEVARCHARNo
The name of the lab record.
26COMP_VERIF_USER_IDVARCHARNo
The unique ID of the user who verified the component.
27COMP_VERIF_USER_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
28USR_OVRD_ABNRML_IDVARCHARNo
The unique ID associated with the user record responsible for overriding abnormality or reference range. This column is frequently used to link to the CLARITY_EMP table.
29USR_OVRD_ABNRML_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
30USR_OVRD_REP_FLG_IDVARCHARNo
The unique ID associated with the user record responsible for overriding the reportable flag. This column is frequently used to link to the CLARITY_EMP table.
31USR_OVRD_REP_FLG_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
32OVRIDE_ABNRML_YNVARCHARNo
Indicates whether users can override the reference range or abnormality from Result Entry.
33OVRIDE_REP_FLAG_YNVARCHARNo
Indicates whether users can override the reportable flag from Result Entry.
34CMP_VERIF_UTC_DTTMDATETIME (UTC) No
Stores the instant in UTC at which the component on the corresponding line was verified.
35COMP_LNC_RECORD_ID_LNC_LONG_NAMEVARCHARNo
The more readable format than the fully specified name in Logical Observation Identifiers Names and Codes (LOINC?) code.
36COMP_ACCREDITED_YNVARCHARNo
This item determines the accreditation status of the corresponding component. If set to Y-Yes, the corresponding component is accredited. If set to N-No, the corresponding component is not accredited. If null, no evaluation was performed on the component to determine if it is accredited or not.
37COMP_UNCERTAIN_MEASVARCHARNo
The extent to which a given value is uncertain (e.g. if the uncertainty percentage is 5%, then the component uncertainty value for a result of 1.00 will be +/- 0.05). NOTE: This is how the data is stored in the database; as string format. This field stores numeric in M internal format, using a period as the decimal separator irrespective of locale.
38COMP_NETWORK_CONCEPT_IDENTVARCHARNo
Stores the network concept identifier associated with this component at the time of resulting.
