CAP_DTL_TX
Description:
The CAP_DTL_TX table contains capitation detailed transactions associated with received capitation files.

Primary Key
Column NameOrdinal Position
TRANSACTION_ID1

NameTypeDiscontinued?

10AR_TX_STATUS_C_NAMEVARCHARNo
The current status for a transaction.
11AR_TX_FILED_DATEDATETIMENo

12AR_TX_REVERSAL_IDVARCHARNo
