TREATMENT_PLAN_AUDIT
Description:
This table contains audit information for the fertility treatment plan. It tracks who changed the plan, when, and what value was changed.

Primary Key
Column NameOrdinal Position
MED_PRBLM_LIST_ID1
LINE2

Column Information
NameTypeDiscontinued?
1MED_PRBLM_LIST_IDNUMERICNo
The unique identifier for the medical problem list record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3MOD_INST_UTC_DTTMDATETIME (UTC) No
Stores the instant in which the change was made to the Treatment Plan.
4MODIFY_USER_IDVARCHARNo
Stores the user who updated the Treatment Plan.
5MODIFY_USER_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
6START_DATEDATETIMENo
Stores the start date of the block for the patient instruction. This is part of the audit trail of changes made to the Treatment Plan.
7END_DATEDATETIMENo
Stores the end date of the block for the patient instruction. This is part of the audit trail of changes made to the Treatment Plan.
8DOSENUMERICNo
Stores the instructed dose for the treatment plan. This is part of the audit trail of changes made to the Treatment Plan.
9UNITS_C_NAMEVARCHARNo
Stores the units for the instructed dose. This is part of the audit trail of changes made to the Treatment Plan.
10FREQ_IDVARCHARNo
Stores the frequency for the administration instructions. This is part of the audit trail of changes made to the Treatment Plan.
11FREQ_ID_FREQ_NAMEVARCHARNo
The name of the frequency record.
12ROUTE_C_NAMEVARCHARNo
Stores the route of administration for the instructions. This is part of the audit trail of changes made to the Treatment Plan.
13MEDICATION_ID_MEDICATION_NAMEVARCHARNo
The name of this medication record.
14ACTION_C_NAMEVARCHARNo
This tracks the action being audited. For example, if the user made a change, it will be audited as a pending change action. When signed, it will be audited as a signed action. This is part of the audit trail of changes made to the Treatment Plan.
