ORD_MED_REFILL_HX
Description:
This table shows Medication Refill History Information.

Primary Key
Column NameOrdinal Position
ORDER_ID1
LINE2

Column Information
NameTypeDiscontinued?
1ORDER_IDNUMERICNo
The unique ID of the refill medication order.
2LINEINTEGERNo
The line number for the information associated with this contact. Multiple pieces of information can be associated with this contact.
3RFL_HX_MED_ID_MEDICATION_NAMEVARCHARNo
The name of this medication record.
4RFL_HX_NDC_CODEVARCHARNo
NDC code for each refill.
5RFL_HX_ACTION_C_NAMEVARCHARNo
Action taken, such as Dispense or Refill.
6RFL_HX_FILL_REMAININTEGERNo
Number of refills remaining.
7RFL_HX_FILL_USEDINTEGERNo
Number of refills used.
8RFL_HX_REFILL_NUMINTEGERNo
Refill number. This is the number of refills used so far. It counts sequentially up from 1.
9RFL_HX_CANCELLED_C_NAMEVARCHARNo
Refill cancellations.
10RFL_HX_SIGVARCHARNo
The description of how a refill medication is to be administered (sig).
11RFL_HX_LONG_SIGVARCHARNo
Long sig for refill. This is a longer version of the sig, and is only populated by the interface in the case where a longer sig needs to be stored.
12REFILL_SUBSTITU_YNVARCHARNo
Was the refill substituted?
13RFL_HX_PERSONVARCHARNo
Refill person, this is a free text field that will depend on interface setup.
14RFL_HX_PHARMACY_IDNUMERICNo
PHR ID of pharmacy that refilled the medication.
15RFL_HX_PHARMACY_ID_PHARMACY_NAMEVARCHARNo
The name of the pharmacy.
16RFL_HX_DATEDATETIMENo
The date the refill medication order was placed.
17RFL_HX_TIMEDATETIMENo
The time the refill medication order was placed.
18RFL_HX_COMMENTVARCHARNo
The comments entered by the user who placed the refill medication order.
19REFIL_HX_DIS_NDC_IDVARCHARNo
This item will hold the NDC related to the dispensed medication that comes through the interface sent from the pharmacy. This item will only be populated through the interface. This item will be networked to the NDC master file.
20REFIL_HX_DIS_NDC_ID_NDC_CODEVARCHARNo
The external code for the National Drug Code (NDC). An NDC represents packages of medications.
21REFIL_HX_DIS_MEDVARCHARNo
This item will hold the dispensed medication name that comes through the interface from the pharmacy. This item will only be populated by the interface.
22REFIL_HX_DISP_QTYUNIT_C_NAMEVARCHARNo
This item will hold the dispense unit quantity for the medication that comes through the interface from the pharmacy. It will only be populated through the interface.
23REFIL_HX_DIS_DURNUMERICNo
This item will hold the duration of the dispense for the medication sent through the interface from the pharmacy. This item will only be populated from the interface.
24REFIL_HX_DUR_UNT_C_NAMEVARCHARNo
This item will hold the duration unit for the medication sent through the interface from the pharmacy. This item will only be populated through the interface.
25REFILL_HX_ACTION_MOD_C_NAMEVARCHARNo
Adds an additional classification to the Refill Hx Action, eg. 'Remediation'
26REFILL_HX_QUANTITY_DISPENSEDNUMERICNo
Quantity dispensed for refill.
