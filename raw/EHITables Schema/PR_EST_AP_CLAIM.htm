PR_EST_AP_CLAIM
Description:
This table stores accounts payable claim context information for managed care estimates.

Primary Key
Column NameOrdinal Position
ESTIMATE_ID1
LINE2

Column Information
NameTypeDiscontinued?
1ESTIMATE_IDNUMERICNo
The unique identifier for the patient estimate record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3VENDOR_IDVARCHARNo
The vendor associated with the estimate claim detail.
4VENDOR_ID_VENDOR_NAMEVARCHARNo
The name of the vendor.
5PROV_ID_PROV_NAMEVARCHARNo
The name of the service provider. This item may be hidden in a public view of the CLARITY_SER table.
6POS_ID_LOC_NAMEVARCHARNo
The name of the revenue location.
7CLAIM_FORMAT_C_NAMEVARCHARNo
The claim format for the estimate claim detail.
8HISTORY_TYPE_C_NAMEVARCHARNo
The type of historical data used for this estimate claim detail.
9HX_UB_CLASS_C_NAMEVARCHARNo
The historical UB claim classification to use for this estimate claim detail.
10POS_TYPE_C_NAMEVARCHARNo
The place of service type of the related line.
11MC_ANCHOR_CONTEXTINTEGERNo
This is the Anchor context, meaning if there are mulitple lines in the related group that come from the same Anchor procedure this number points to the line that has the Anchor procedure. The Anchor procedure is what is shown to the member in Cost Calculator.
12MC_SEARCH_CONTEXTINTEGERNo
Holds a line number that corresponds to a line in RG PES 18180 which has the related search parameters that were in use when the detailed view was selected.
