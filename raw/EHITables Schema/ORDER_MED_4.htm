ORDER_MED_4
Description:
This table enables you to report on medications ordered. This table should be used with ORDER_MED.

Primary Key
Column NameOrdinal Position
ORDER_ID1

Column Information
NameTypeDiscontinued?
1ORDER_IDNUMERICNo
The unique identifier for the order record.
2E_PRES_EARLIEST_DATDATETIMENo
This column stores the earliest date on which a prescription can be filled for a Schedule II controlled medication. The date must occur on or before the start date for the prescription. It can't be changed after the order is signed.
3PRESC_ORD_SIGVARCHARNo
The originally prescribed medication instructions for an order. This will be null if the original and current medication instructions are identical or if the order is not for a controlled medication that was electronically prescribed.
4PRESC_ORD_MED_NAMEVARCHARNo
The originally prescribed medication name for an order. This will be null if the original medication name and current medication name are identical or if the order is not for a controlled medication that was electronically prescribed.
5PRESC_ORD_REFILLSVARCHARNo
The originally prescribed refills for an order. This will be null if the original refills and current refills are identical or if the order is not for a controlled medication that was electronically prescribed.
6PRESC_ORD_QUANTITYVARCHARNo
The originally prescribed quantity for an order. This will be null if the original quantity and current quantity are identical or if the order is not for a controlled medication that was electronically prescribed.
7INTERFACE_STAT_C_NAMEVARCHARNo
This column stores the ID of the interface status of the order.
8WAS_FMLY_CHECKED_YNVARCHARNo
Indicates whether the medication order was compared to a formulary during signing. 'Y' indicates that the medication was compared to a payor-plan formulary, external formulary, or hospital formulary. 'N' or NULL indicates that the medication was not compared to a formulary. This does not indicate that the medication is or is not on any formulary, only that a formulary was checked for the medication.
9ORDER_CONTEXT_IDNUMERICNo
The unique identifier of the order context record associated with the order, which contains additional information about when the order is intended to be used.
10PREV_ORD_CONTEXT_IDNUMERICNo
The unique identifier of the order context record associated with the order, which contains additional information about when the order is intended to be used.
11PARENT_ORDER_IDNUMERICNo
The unique ID of the parent order record for Home Health (HH) orders. An HH order is an order which represents documentation by a user whose scope of practice doesn't include editing prescription data. Furthermore, the child order created will not be an actual prescription, but merely represents new instructions to the patient regarding how to take a medication.
12LINKED_OP_MED_IDNUMERICNo
The unique ID of the orders record. When Home Health and Hospice clinicians need to document a medication administration against an inpatient medication, a copy of the medication is created with an order mode of inpatient to document the administration. This column holds a link to the original outpatient medication.
13TXT_AUTHPROV_EXT_YNVARCHARNo
Indicates whether the order's authorizing provider is from an external provider database. 'Y' indicates that the provider does not have a provider record in this EHR system and is from an external provider database. 'N' or NULL indicates that the provider has a provider record in this EHR system.
14TXT_ORDPROV_EXT_YNVARCHARNo
Indicates whether the order's ordering provider is from an external provider database. 'Y' indicates that the provider does not have a provider record in this EHR system and is from an external provider database. 'N' or NULL indicates that the provider has a provider record in this EHR system.
15TRANSIG_LANGUAGE_IDNUMERICNo
The unique identifier of the language record used for translating patient-facing information in this order record.
16TRANSIG_LANGUAGE_ID_LANGUAGE_NAMEVARCHARNo
The language name. If the language is written and uses more than one script to represent it, the name will contain the script in parentheses after the language name.
17MAX_DAILY_DOSENUMERICNo
Max daily dose value entered by the provider or defaulted as the calculated daily dose
18MAX_DLY_DOSE_UNIT_C_NAMEVARCHARNo
The unit category ID for the orders record
19SELECTED_CRCL_SRC_C_NAMEVARCHARNo
The selected CrCl source category ID for the order record, indicating the source of the creatinine clearance (CrCl) value.
20CRCL_ORD_SPEC_VALNUMERICNo
This column stores the creatinine clearance (CrCL) value in the order.
21SELECTED_SCR_SRC_C_NAMEVARCHARNo
The selected sCr source category ID for the order record, indicating the source of the serum creatinine (sCr) value.
22SCR_ORD_SPEC_VALNUMERICNo
The serum creatinine (sCr) value for the order record.
23ORIG_DOSE_BEFORE_SWITCHVARCHARNo
The original dose of the medication before the dose was adjusted.
24ORIG_DOSE_UNIT_BEFORE_SWITCH_C_NAMEVARCHARNo
The unit category ID for the order record.
25MAXDOSE_HARDSTOP_YNVARCHARNo
Indicate whether the max dose limit is a hard stop for this order. If "Yes", the max dose is a hard stop. Otherwise, the max dose is not a hard stop.
26TXT_AUTHPROV_DIST_C_NAMEVARCHARNo
The district category ID associated with the authorizing provider for this order record.
27TXT_AUTHPROV_CTY_C_NAMEVARCHARNo
The county category ID associated with the authorizing provider for this order record.
28TXT_AUTHPROV_CTRY_C_NAMEVARCHARNo
The country category ID associated with the authorizing provider for this order record.
29TXT_ORDPROV_HOUSEVARCHARNo
The house number of the ordering provider for this order record.
30TXT_ORDPROV_DIST_C_NAMEVARCHARNo
The district category ID associated with the ordering provider for this order record.
31TXT_ORDPROV_CNTY_C_NAMEVARCHARNo
The county category ID associated with the ordering provider for this order record.
32TXT_ORDPROV_CNTRY_C_NAMEVARCHARNo
The country category ID associated with the ordering provider for this order record.
33MAX_BSANUMERICNo
The maximum Body Surface Area (BSA) for an order, if the selected BSA is greater than this BSA then the selected BSA will be capped at this value.
34TXT_AUTHPROV_HOUSEVARCHARNo
The house number of the authorizing provider for this order record.
35UNROUNDED_DOSE_MINNUMERICNo
The unrounded dose of this order. If the dose has a range (e.g. 1-2 mg), this is the lower end of the range. If the dose does not have a range, then this will store the dose.
36UNROUNDED_DOSE_MAXNUMERICNo
The unrounded dose of this order. If the dose has a range (e.g. 1-2 mg), this is the upper end of the range. Otherwise, this is null.
37UNROUND_DOSE_UNIT_C_NAMEVARCHARNo
The med & dose unit category ID for the unrounded dose of this order record.
38ION_SPEC_AC_AMTNUMERICNo
This column shows the amount of acetate that a provider entered in this order record. This column will be empty if a chloride:acetate ratio or maximize option was selected.
39ION_SPEC_AC_UNIT_C_NAMEVARCHARNo
The med & dose unit category ID for the acetate amount that a provider entered in this order record. This column will be empty if a chloride:acetate ratio or maximize option was selected.
40ION_MAXIMIZE_C_NAMEVARCHARNo
The ion maximize selection category ID for the order record.
41ION_RATIOVARCHARNo
This column shows the chloride:acetate ratio option that was selected. This column is empty when a specified acetate amount was entered or when a maximize option was selected.
42ION_BASED_TPN_YNVARCHARNo
This column indicates how users specify electrolyte amounts for a total parenteral nutrition (TPN) order. 'Y' indicates that users enter amounts for specific ions to add in the TPN. 'N' indicates that users enter amounts for specific salts to add in the TPN.
43CALC_CL_AC_RATIONUMERICNo
This column stores the calculated chloride:acetate ratio for an ion-based total parenteral nutrition (TPN).
44ION_PRI_CALC_AMT_C_NAMEVARCHARNo
This column indicates whether the primary calculated amount is a weight-based or non-weight-based value.
45USE_AUC_DOSE_YNVARCHARNo
Indicates whether the system should automatically update the dose for the order based on the area under the curve (AUC) calculations. 'Y' indicates that the system updates the dose based on AUC calculations. 'N' or NULL indicates that the system does not update the dose based on AUC calculations.
46EPRES_PHARMACY_ID_EXTERNAL_NAMEVARCHARNo
The external name of the department record. This is often used in patient correspondence such as reminder letters.
47EPRES_PHARMACIST_IDVARCHARNo
This column stores the ID of the pharmacist or pharmacy technician who accepted the prescription.
48EPRES_PHARMACIST_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
49RX_ACCEPT_DTTMDATETIME (Local) No
Stores the instant at which the prescription was accepted.
50RPTSIG_EXISTS_YNVARCHARNo
Indicates whether the patient has indicated that they are taking this med differently from how it was prescribed to them for this order. If yes, the patient reported that they are taking the med differently. If no or null, the patient did not report that they are taking the med differently.
51HOLD_PENDING_PA_YNVARCHARNo
This item indicates whether the order is waiting for a prior authorization request to be completed before being sent to its final destination.
52SEND_PA_REQ_YNVARCHARNo
Indicates whether a prior authorization request should be sent for a medication order when it is signed. 'Y' indicates that a prior authorization request should be sent. 'N' indicates that a prior authorization request should not be sent.
53PA_ORG_IDNUMERICNo
The unique ID of the data exchange organization associated with the order record, which specifies the payer that a prior authorization request should be sent to when a medication order is signed.
54PA_ORG_ID_EXTERNAL_NAMEVARCHARNo
Organization's external name used as the display name on forms and user interfaces.
55SCRIPT_SUP_ID_PROV_NAMEVARCHARNo
The name of the service provider. This item may be hidden in a public view of the CLARITY_SER table.
56DISC_WAIT_PA_YNVARCHARNo
This column indicates whether an order was discontinued while waiting for prior authorization.
57ONE_STEP_MEDPROC_IDNUMERICNo
The unique ID of the order record. This item points to a procedure order record for the procedure used to administer the medication. The item is populated when administering a medication that is documented as administered in an Ophthalmology or Orthopedic context.
58SPEC_DOSE_LMT_HRINTEGERNo
The number of hours the dosing limit represents.
59SPEC_MED_TYPE_C_NAMEVARCHARNo
The special medication type category ID for this order. This indicates whether the medication uses special dosing parameters, such as for patient-controlled analgesia orders.
60RX_TRANSITION_IDNUMERICNo
The unique identifier for the patient follow-up tracking record, which stores information about how a patient is transitioning from one medication to another.
61RX_TRANSITION_STAT_C_NAMEVARCHARNo
The medication transition status category ID for the order record.
62RX_TRANSITION_STAT_RSN_C_NAMEVARCHARNo
The medication transition status change reason category ID for the order record.
63RX_TRANSITION_STAT_CMTVARCHARNo
This item stores any additional comments about why the medication transition status was changed.
64RX_TRANSITION_STAT_USR_IDVARCHARNo
The unique identifier of the user who changed the transition status of the medication.
65RX_TRANSITION_STAT_USR_ID_NAMEVARCHARNo
The name of the user record. This name may be hidden.
66RX_TRANSITION_STAT_UTC_DTTMDATETIME (UTC) No
The date and time the medication transition status of the order was changed.
67DISCON_LOCAL_TIMEDATETIME (Local) No
This item stores the instant in the patient's local time zone that an order was discontinued.
68RX_REQUEST_TYPE_C_NAMEVARCHARNo
The prescription request type category ID for the order record
69ERX_ORD_NAMEVARCHARNo
The name of an order that was electronically prescribed.
