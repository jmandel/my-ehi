ORDER_MED_2
Description:
This table enables you to report on medications ordered in EpicCare or Ambulatory Pharmacy (Prescriptions).
This table should be used with ORDER_MED.

Primary Key
Column NameOrdinal Position
ORDER_ID1

Column Information
NameTypeDiscontinued?
1ORDER_IDNUMERICNo
The unique ID of the order record associated with this medication order. This is an internal unique identifier for order records in this table and cannot be used to link to CLARITY_MEDICATION.
2TXT_AUTHPROV_NAMEVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's name.
3TXT_AUTHPROV_DEAVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's Dynamic Epic Advisory Database (DEA) number.
4TXT_AUTHPROV_PHONEVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's phone number.
5TXT_AUTHPROV_FAXVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's fax number.
6TXT_AUTHPROV_STREETVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's street address information.
7TXT_AUTHPROV_CITYVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's city.
8TXT_AUTHPROV_ZIPVARCHARNo
In ambulatory pharmacy, a prescription order could be authorized by a non-EpicCare provider. There is no provider record for this provider. This is used to store the non-EpicCare provider's zip code.
9RX_NUM_FORMATTEDVARCHARNo
The formatted prescription number for the order.
10RX_COMMENTSVARCHARNo
In an ambulatory pharmacy, the person who enters the prescription into the system can add additional comments to the prescription. The comments are not part of the order and are used for pharmacy internal communication only. The comments do not affect the patient instructions, nor the dispense information.
11RX_WRITTEN_DATEDATETIMENo
Store the prescription written date, which is the date the prescription was entered into the system through EpicCare, or the date the prescription was written to the paper prescription.
12EFQ_OVRD_DAY_TYPENUMERICNo
Specifies what the numeric values in the frequency override days columns represent. If it is 1 then the listed days are relative days. If it is 2 then the listed days are weekdays. Any other value has no meaning.
13EFQ_OVRD_CYCL_LENNUMERICNo
If there is a frequency override specified, this item will contain the length of a relative specified type cycle. For all other specified types this value will be ignored (and should be empty).
14CHART_CORRECTION_IDNUMERICNo
For chart corrections, links the order to a Chart Correction Audit (CCA) record.
15PARENT_CE_ORDER_IDNUMERICNo
When a cross-encounter order is released, this item stores the ID of the parent order.
16TPL_WT_SRC_C_NAMEVARCHARNo
The weight source of the treatment plan for this order, as of the time the order is signed.
17OVERRIDE_LINKED_C_NAMEVARCHARNo
The linked override resolved category number for the medication order. The category indicates whether the admins in the override pull are all linked to pharmacy orders.
18CONDITIONAL_C_NAMEVARCHARNo
Identifies an inpatient order as "conditional".
19COND_STATUS_C_NAMEVARCHARNo
For a conditional order, indicates whether the conditions for the order have been satisfied yet.
20PEND_REF_REAS_COMMVARCHARNo
Extracts the comment attached to the pend refusal reason (I ORD 7706)
21PRIORITIZED_INST_TMDATETIME (Local) No
The time and date that is used as the prioritized date.
22ORDER_QUESN_LISTVARCHARNo

23EXT_PHARM_MED_NAMEVARCHARNo
Medication display name received from an external pharmacy.
24PEND_MED_ACTIVE_YNVARCHARNo
A flag to determine if this is an active pending medication or not.
25PEND_PREV_ORD_IDVARCHARNo
The previous order ID for the pending medication. This item is NOT networked to orders.
26TXT_AUTHPROV_NPIVARCHARNo
If the authorizing provider for a medication is not currently an Epic provider (no SER record for this provider), free text provider items are used to save information about this provider. This item stores the National Provider ID (NPI) of the provider.
27ORD_TRANS_METHOD_C_NAMEVARCHARNo
This item holds the method of transmission for a given order. It should only be set from within an order transmittal rule using the transmission method property (LRC 161).
28PROFILE_ONLY_RX_YNVARCHARNo
This item specifies whether the medication order is intended to be filled by the pharmacy immediately or should be filled later when requested by the patient. This flag can be set in order entry based on the order class or by selecting the 'profile only' checkbox in pharmacy order entry.
29DISP_QTY_REMNUMERICNo
Stores the remaining authorized quantity (in Written Dispense Quantity unit) that the pharmacist can dispense. It is used in Ambulatory Pharmacy to calculate the Refills Remaining.
30FREQ_UNSCHEDULED_C_NAMEVARCHARNo
If the frequency is unscheduled, this column will store a 1. If the frequency is not unscheduled, this column will be blank.
