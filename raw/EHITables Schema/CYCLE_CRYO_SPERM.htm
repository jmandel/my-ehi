CYCLE_CRYO_SPERM
Description:
Contains information about the sperm that was cryopreserved as part of a fertility treatment cycle.

Primary Key
Column NameOrdinal Position
RECORD_ID1
LINE2

Column Information
NameTypeDiscontinued?
1RECORD_IDNUMERICNo
The unique identifier for the cycle record.
2LINEINTEGERNo
The line number for the information associated with this record. Multiple pieces of information can be associated with this record.
3CRYO_SPERM_ID_NAMEVARCHARNo
Stores a custom ID title for the cryopreservation. If not set, a generated default will be shown to the user, based on the line number.
4CRYO_SPERM_DATEDATETIMENo
Stores the date of cryopreservation for sperm.
5SPERM_EMBRYO_GAMETE_SOURCE_C_NAMEVARCHARNo
Stores the cryopreserved sperm source, such as from a partner or donor.
6SPERM_EMBRYO_GAMETE_STATE_C_NAMEVARCHARNo
Stores the cryopreserved sperm state at the beginning of the cycle, such as fresh or thawed.
7CRYO_SPERM_DONORVARCHARNo
Stores the cryopreserved sperm donor ID.
8CRYO_SPERM_COLL_C_NAMEVARCHARNo
Stores the cryopreserved sperm's collection method.
9CRYO_SPERM_VOLUMENUMERICNo
Stores the cryopreserved sperm's volume in milliliters.
10CRYO_SPERM_CONCENNUMERICNo
Stores the cryopreserved sperm's concentration, in millions per milliliter.
11CRYO_SPERM_MOTILITYINTEGERNo
Stores the cryopreserved sperm's motility, in percent.
12CRYOSPM_PROGRESS_C_NAMEVARCHARNo
Stores the cryopreserved sperm's grade of progression.
13CRYO_SPERM_MORPHOLOGYINTEGERNo
Stores the cryopreserved sperm's morphology, as a percent that are normal.
14CRYO_SPERM_FROZ_VIALSINTEGERNo
Stores the number of vials frozen for cryopreserved sperm.
15CRYO_SPERM_VOL_PER_VIANUMERICNo
Stores the volume per vial for the cryopreserved sperm, in milliliters.
16CRYO_SPERM_COLLECT_COMMENTVARCHARNo
Stores the comments for the collection method for the cryopreserved sperm.
17CRYO_SPERM_COMMENTSVARCHARNo
Stores cryo specific comment for sperm.
